## 最新完整训练集与真实串行测试

2026-10-05 完成：VLM 使用 11,959 张官方训练图、400 张固定开发图；所有新推理路径使用同一批 3,421 张官方测试图。冻结 CNN 沿用历史 4,000 图训练的线性分类器。

| 路径 | 正确/总数 | Accuracy | Macro-F1 | VLM 调用 | 平均延迟 | P95 |
|---|---:|---:|---:|---:|---:|---:|
| 冻结 WR50 + 线性分类器 | 3204/3421 | 93.6568% | 93.2454% | 0 | 10.61 ms | 16.57 ms |
| 完整训练集 LoRA VLM | 3325/3421 | 97.1938% | 97.0118% | 3421 | 533.09 ms | 662.72 ms |
| CNN → 条件 VLM | 3335/3421 | 97.4861% | 97.4888% | 801（23.4142%） | 139.04 ms | 651.80 ms |

三条路径实际逐图推理，同一 RTX 3090、batch=1、并发=1、无预取。从读图到最终类别输出同步计时，排除加载、暖机和写文件；文件缓存未清空。路由相对全量 VLM 平均延迟降低 73.92%，串行计时吞吐为 7.192 vs 1.876 图/秒；不作为多并发服务吞吐。P95 的 VLM 接管成本仍存在。

路由纠正冻结 CNN 的 164 个错误，同时引入 33 个错误，净增 131 个正确预测。对已接管样本，路由输出与本轮全量 VLM 输出一致。

模型从 base 新建 r=4、alpha=8 LoRA，共训练 23,918 步。开发集 Macro-F1 选定 step_18000（dev accuracy 99.00%）；max probability 门控在不超过 30% 开发调用预算下选定，阈值 0.9950015136477659，dev 调用 83/400。选模和阈值在本次测试前保存。

离线回放调用 800 张，真实串行调用 801 张：一张图因 batch=64 与 batch=1 的 TF32 概率差异跨过同一阈值，分类结果不变。实际数值记录见[附件](../results/fulltrain-20261005/numerical-diagnostic.json)。

旧 4,000 图 LoRA 准确率为 94.68%，新模型为 97.19%；训练规模、类别比例、初始化和更新过程同时改变，不能归因于单一因素。历史全量微调 WR50 仍为 98.07%，高于路由；不同训练量的模型不作为同预算公平消融。测试集已有历史使用，本轮是后续优化。

完整逐图类别、调用与延迟位于[公开附件](../results/fulltrain-20261005/)，标准库命令 `python scripts/recompute_fulltrain_metrics.py` 可重算。训练与实测命令见[完整训练集复现](FULLTRAIN_REPRODUCE.md)。下方历史实验保留其原协议和成绩，rank/VisA 结论不自动迁移至新适配器。

## 适配器选型：固定 400 图开发集

初训最佳适配器准确率 91.50%。扩量续训后，新增 step1000=95.00%、step2000=94.50%、step3000=96.75%、step4000=95.50%、step5000=96.50%、step6000=96.50%。最终跑满新增 8,000 步，开发集最佳仍为 step3000（macro-F1 96.7449%）。最终报告采用这一固定模型。

初训与扩量同时改变了数据量、学习率和训练过程。这一实验记录整体训练方案的收益；独立的 rank 容量对照见下一节。

## 独立 rank 消融：400 图开发集

三组从同一 Qwen3.5-4B base 新建 LoRA，使用相同 4,000 图训练集、400 图开发集和 8,000 步训练计划，固定 alpha/r=2。每 1,000 步评估，按 macro-F1、accuracy、较早 step 选择。

| Rank | Alpha | 可训练参数 | 最佳 step | Dev Macro-F1 | Dev Accuracy |
|---:|---:|---:|---:|---:|---:|
| 2 | 4 | 229,376 | 8,000 | 96.9708% | 97.00% |
| 4 | 8 | 458,752 | 5,000 | 97.0140% | 97.00% |
| 8 | 16 | 917,504 | 8,000 | 96.6821% | 96.75% |

r=4 的开发集 macro-F1 点估计最高，r=2 仅低 0.0432 个百分点，r=8 未带来收益。这支持保留 r=4 为默认容量点，并将 r=2 视作更省参数的近似方案。当前为单 seed 对照，细小差异需跨 seed 验证。

本轮只评估开发集，与旧热启动模型和新完整训练集模型具有不同训练历史；checkpoint 和分数独立记录。设置、结果与可核算混淆矩阵见 [Rank 消融](RANK_ABLATION.md)。

## 外域回归：VisA 工业图像二分类

在固定的 723 张工业图像子集上，对原始 Qwen3.5-4B 与血细胞 LoRA step_03000 做配对推理。子集包含 capsules（241 正常 / 40 异常）和 pcb1（402 正常 / 40 异常），共 643 张正常、80 张异常。此结果不用于重新选择 checkpoint。

| 指标 | 原始模型 | 血细胞 LoRA |
|---|---:|---:|
| Balanced accuracy | 53.125% | 55.000% |
| 异常召回率 | 6.25%（5/80） | 10.00%（8/80） |
| 正常图误报率 | 0% | 0% |
| Accuracy | 89.63%（648/723） | 90.04%（651/723） |
| 无效输出数 | 0 | 0 |
| 原始回答含血细胞类别词的数量 | 0 | 0 |

配对结果：双方均正确 648 张、双方均错误 72 张，LoRA 纠正 3 张、没有新增错误。两次推理均采用 greedy、关闭 thinking、max_new_tokens=32，像素预算为 65,536–200,704。

**该子集未观察到退化。** 类别分布偏向正常图，全部预测正常即可获得 88.94% accuracy，因此优先看 balanced accuracy 和异常召回。两者异常检测能力仍弱，本项仅为有限外域回归证据，不代表通用能力全面保持，也不是整个 VisA 数据集的性能结论。聚合记录见 [外域指标](../results/external_domain_metrics.json)。
