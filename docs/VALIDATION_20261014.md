# BloodRoute 补充实验报告

本轮固定完整训练模型step_18000；不更换checkpoint，历史完整测试和新诊断子集分别报告。

## 本轮主要结论

- 固定800张均衡诊断图：基座Accuracy 61.88%、Macro-F1 57.32%；当前LoRA Accuracy 97.38%、Macro-F1 97.40%，两者正常图像输出均无格式无效样本。
- LoRA替换图像后对原标签仅0.25%，对新图像标签仍97.38%；空白和纯文本均12.5%。支持领域适配改善图像分类与图像依赖，不单独证明具体医学形态特征。
- 正常图像LoRA纠正289个基座错误，引入5个错误，净增284；配对Accuracy提升35.50个百分点，95% bootstrap区间约32.00–39.00个百分点。
- 发现训练—测试5组精确像素重复，含1组标签冲突；剔除后历史LoRA完整测试Accuracy为97.22%，影响很小。没有患者ID，患者级泛化未验证。
- 当前LoRA的VisA Balanced Accuracy从基座53.13%到53.75%，异常Recall从6.25%到7.50%；该子集未观察到下降，但两者异常识别均较弱，不能作为广泛通用能力保留的充分证据。
- 闭源VLM对照尚未完成。历史完整测试与新800张均衡子集分别报告。

## 数据检查

- 实际训练11959张、开发400张、测试3421张；跨集合source_id交叉均为0。
- 跨集合解码RGB像素完全重复共6组：训练—开发1组、训练—测试5组；测试重复图占5/3421＝0.1462%。
- 1组像素相同但类别标签不同，保留原标签，不自行纠正。
- DCT pHash距离<=4另发现1组训练—测试近重复候选。已查看并排图片，视觉高度相似；候选不自动等同于同一患者或泄漏。
- 实际输入只传图像像素与统一问题，不传类别标签、答案、文件名、source_id。数据清单没有患者ID，不能证明患者独立划分。
- 原测试已有多轮使用，这些检查和分数属于追加诊断，不称新独立盲测。

## 公开附件与离线复核

[诊断附件](../results/validation-20261014/)提供冻结协议、两模型逐样本原始回答与解析、推理配置、像素重复审计和聚合结果；不含图像、模型权重或内部运行日志。常量条件虽按800个标签展开评分，每模型每条件实际只推理一次。

`python scripts/recompute_followup_metrics.py` 从公开预测重算图像干预、外域及去重敏感性结果。它重算评分，不重新训练或执行模型。历史原始完整测试保留在[fulltrain附件](../results/fulltrain-20261005/)。
